# ReconX

## Problem Statement

Financial institutions process large volumes of transactions across payment systems, settlement systems, and bank accounts. Differences between expected and actual transaction amounts can occur due to processing delays, fees, duplicate records, missing transactions, or failed transfers.

ReconX is a financial transaction reconciliation system designed to compare payment and settlement records with bank statement data, identify mismatches, and help users investigate reconciliation exceptions.
